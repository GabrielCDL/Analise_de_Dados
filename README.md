# 📊 Análise de Desempenho - Brasileirão (Série A)

## 📌 Sobre o Projeto
Este projeto tem como objetivo analisar o histórico e o desempenho dos clubes participantes da Série A do Campeonato Brasileiro ao longo dos últimos 10 anos. O fluxo de trabalho abrange desde a extração e tratamento dos dados até a construção de um dashboard interativo.

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Python (Biblioteca Pandas):** Importação, limpeza, tratamento e transformação do banco de dados em formato CSV.
* **Power BI:** Construção do dashboard interativo e exploração visual de indicadores (como pontos, aproveitamento, vitórias e gols).
